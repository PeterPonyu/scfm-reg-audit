Capsule

Reproducibility

This GitHub tree is an audit capsule. Cloning it and running the validator is not a full production rerun. Dual-null Support ≠ protocol-pass ≠ recovery. Protocol-pass is 0/13.

How the audit is computed

Partial Spearman of a frozen foundation-model gene graph versus the accessibility/motif proxy, residualized on a named confound design. Two Monte Carlo nulls (N=999, plus-one p): gene-label (Mantel-style) and degree-preserving within-TF shuffle. Support requires both BH-adjusted q values < 0.05 in the same confound-spec.

Three layers

  1. 1. Artifact validation — no downloads. From a capsule clone: python validate_artifacts.py and python -m unittest discover -s src/tests.
  2. 2. Statistical reruns — needs the datasets below plus cached FM graphs in results/v2/*.npz (not redistributed).
  3. 3. Full pipeline — datasets + model weights + vendor code. Experiment workspace only. Boundary note: FULL_RERUN.md.
